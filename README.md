# Virtual Terminal

Виртуальный терминал

## Как запустить программу

### Компиляция

```bash
g++ main.cpp terminal.cpp entry.cpp directory.cpp file.cpp singlelinefile.cpp multilinefile.cpp -o terminal.exe

запуск: .\terminal.exe

Поддерживаемые команды:

help	- Показать список команд	
exit	- Выйти из терминала	
pwd	- Показать текущий путь	
ls	- Показать содержимое текущей директории	
cd <dir>	- Перейти в директорию	
mkdir <dir>	- Создать директорию	
touch <file>	- Создать однострочный файл	
touchm <file>	- Создать многострочный файл	
edit <file>	- Редактировать файл	
cat <file>	- Показать содержимое файла	
mv <old> <new>	- Переименовать файл/директорию	
rm <name>	- Скрыть файл/директорию (мягкое удаление)	
restore <name>	- Восстановить скрытую сущность	

Архитектурные решения

Entry (базовый класс)
├── Directory (директория)
└── File (абстрактный файл)
    ├── SingleLineFile (однострочный файл)
    └── MultiLineFile (многострочный файл)

1. скрытность внутри Entry
2. фильтрация скрытых файлов при выполнении ls происходит в методе Directory::list()
3. поиск сущности по имени реализован В классе Directory метод findChild()
4. текущий путь организован через хранение вектор пути
5. переход между директориями реализован через вектор указателей
